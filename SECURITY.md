# Security

EmberGate is under active development. There is currently no supported stable
release or published security response SLA. Review the deployment guidance in
[README.md](README.md), keep the management listener private, and protect the data
directory and encrypted backup passphrases.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** option if private
vulnerability reporting is enabled. Otherwise contact the repository owner
privately through a contact method on their GitHub profile. Do not post an
unpatched vulnerability, credentials, private keys, or installation backups in a
public issue. If no private channel is available, open an issue requesting a
private reporting contact without including exploit details.

Include the affected revision, impact, prerequisites, and a minimal reproduction
using dummy credentials and local fixtures when possible. Coordinate disclosure
with the maintainer.

The maintainer should enable GitHub private vulnerability reporting before
making this repository public.
