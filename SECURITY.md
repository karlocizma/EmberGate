# Security

EmberGate is under active development. There is currently no supported stable
release or published security response SLA. Review the deployment guidance in
[installation guide](docs/installation.md), keep the management listener private, and protect the data
directory and encrypted backup passphrases.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
[Security → Report a vulnerability](https://github.com/karlocizma/EmberGate/security/advisories/new).
Only the maintainer sees the report until an advisory is published. Do not post
an unpatched vulnerability, credentials, private keys, or installation backups
in a public issue.

Include the affected revision, impact, prerequisites, and a minimal reproduction
using dummy credentials and local fixtures when possible. Coordinate disclosure
with the maintainer.
